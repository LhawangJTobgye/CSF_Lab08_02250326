# CSF101 - Lab 8: Graph Data Structure and Traversal Algorithms

# Overview #
This lab implements a graph data structure using an adjacency list in Python,
along with core graph traversal algorithms. Each task is written as a
self-contained panel with its own imports and data, so any section can be
run independently without relying on code from other tasks.

# Tasks #

Part A(Task 1): Build a graph using an adjacency list
Part B(Task 2): Dynamically add vertices and edges
Part C(Task 3): Breadth-First Search (BFS) traversal
Part D(Task 4): Depth-First Search (DFS) traversal
Part E(Task 5): Compare BFS and DFS side by side
Part F(Task 6): Find shortest path using BFS
Part G(Task 7): Analyse graph properties

# How to Run #
Make sure you have Python 3 installed, then run:
```bash
python CSF101_LAB8.py
```

# Requirements #
- Python 3.x
- No external libraries — only the built-in `collections.deque`

# Key Concepts Covered #
- Graph representation using adjacency lists
- BFS using a queue (`collections.deque`)
- DFS using recursion
- Shortest path finding in an unweighted graph
- Graph property analysis (degree, connectivity, edge count)
